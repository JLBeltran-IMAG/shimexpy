# Spatial Harmonic and Mesh-based X-ray Imaging

Shimexpy is an open-source Python package for contrast reconstruction, analysis,
and visualization in spatial harmonic and mesh-based X-ray imaging.

## Why Shimexpy?

<div class="shim-card-grid" markdown="1">

[
  <strong>Multicontrast Imaging</strong>
  <span>
    Retrieve absorption, dark-field, and differential phase contrast information from X-ray measurements using Spatial Harmonic Imaging.
  </span>
][multicontrast]{ .shim-card }

[
  <strong>Image Reconstruction</strong>
  <span>
    Process experimental data through Fourier-based harmonic extraction, contrast retrieval, and phase reconstruction.
  </span>
][reconstruction]{ .shim-card }

[
  <strong>Scientific Workflows</strong>
  <span>
    Build reproducible imaging workflows with Python. Integrate preprocessing, reconstruction, visualization, and quantitative analysis.
  </span>
][workflows]{ .shim-card }

[
  <strong>Open Source</strong>
  <span>
    Shimexpy is freely available under the Apache 2.0 license, encouraging scientific collaboration, reproducibility, and further development.
