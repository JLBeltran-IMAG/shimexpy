# API Reference

The Python API is organized by task:

- [Core Functions](core.md): Fourier processing, contrast retrieval, and phase unwrapping.
- [I/O Functions](io.md): load and save images, harmonic grids, and results.
- [Utilities](utils.md): image cropping and flat-field correction.
- [Visualization](visualization.md): visualization tools for displaying reconstructed contrasts.
- [Data Structures](data.md): current status of the data module.
