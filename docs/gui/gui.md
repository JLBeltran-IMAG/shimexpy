# Graphical User Interface

The `shimexpy_gui` package provides a PySide6 desktop interface.

## Install from the repository

After [installing the core library](../getting-started/getting-started.md), run
this command from the repository root in the same virtual environment:

```bash
python -m pip install ./shimexpy_gui
```

## Launch

```bash
shimexpy
```

The graphical interface requires a desktop session. A detailed walkthrough of its
controls is not yet available.
